# หน้าหลักและหน้ารายการสินค้า

> กลับไปหน้าหลัก: [../CLAUDE.md](../CLAUDE.md)

## หน้าหลัก (Home)

ประกอบด้วยส่วนต่างๆ เรียงตามลำดับนี้:

1. **Hero** — แบนเนอร์/สินค้าเด่นประจำร้าน (ตั้งค่าได้จาก admin)
2. **แถบหมวดหมู่/filter ด่วน** — ปุ่มลัดไปหมวดหมู่, จังหวัดยอดนิยม, หลวงพ่อยอดนิยม
3. **พระเครื่องเข้ามาใหม่ (New arrivals)**
   - ดึง `Product` ที่ `createdAt` อยู่ภายใน 30 วันล่าสุด นับจากเวลาปัจจุบัน (`now() - 30 days`)
   - เรียงจากใหม่ไปเก่า (`createdAt DESC`)
   - แสดงเป็น grid/carousel พร้อมป้าย "ใหม่" บนการ์ดสินค้า
   - ถ้าช่วง 30 วันล่าสุดไม่มีสินค้าใหม่เลย ให้ซ่อนส่วนนี้ทั้งหมด (ไม่ต้องโชว์ section ว่างเปล่า)
   - เตรียม query/endpoint แยกไว้ เช่น `GET /api/products?sort=newest&days=30` เพื่อให้ปรับจำนวนวันได้ในอนาคตโดยไม่ต้องแก้โค้ดหน้าเว็บ
4. **สินค้าขายดี (Best sellers)** — เรียงตามยอดขาย/จำนวนคำสั่งซื้อ
5. **แนะนำตามจังหวัด/หลวงพ่อ** — บล็อกลิงก์ไปหน้า `/provinces/[slug]` และ `/monks/[slug]` ยอดนิยม

## หน้ารายการสินค้าและหน้าที่เกี่ยวข้อง

- หน้ารายการสินค้า พร้อม filter แบบ multi-select: จังหวัด, หลวงพ่อ/วัด, หมวดหมู่, ช่วงราคา (สะท้อนใน URL query string เสมอ ดู [Conventions ในหน้าหลัก](../CLAUDE.md#conventions))
- หน้ารายละเอียดสินค้า: รูปหลายมุม, ประวัติพระรุ่นนั้น, ข้อมูลหลวงพ่อผู้สร้าง, ใบรับรอง
  - แกลเลอรีรูปเรียงรูปพระปกติ (`ProductImage.imageType = "product"`) ก่อนเสมอ แล้วต่อท้ายด้วยรูปใบรับประกัน (`imageType = "certificate"`) ถ้าสินค้านั้น `hasCertificate = true` — ดูโครงสร้างตารางและ query เรียงลำดับที่ [database.md](./database.md)
  - ฟอร์มเพิ่ม/แก้ไขสินค้าฝั่ง admin ต้องมีสวิตช์ "มีใบรับประกัน" — เมื่อเปิดใช้งานถึงจะแสดงช่องอัปโหลดรูปใบรับประกัน (แยกจากช่องอัปโหลดรูปพระปกติ) และช่องกรอกรายละเอียดใบรับรอง
- หน้าโปรไฟล์หลวงพ่อ/วัด (`/monks/[slug]`) รวมพระทุกรุ่นของหลวงพ่อนั้น
- หน้าตามจังหวัด (`/provinces/[slug]`) รวมพระทุกองค์จากจังหวัดนั้น
